# 2026-09-26

## flc v1.3 — 无线（Wi-Fi）连接 iPhone + 发版

- 实现无线支持：新增 `flc wifi` 命令组（status/on/off/list/browse/pair），`flc set` 增加
  `--wifi|-w` 与 `--udid|-U`，`flc ddi install [UDID]`；`server status` 显示 Wi-Fi 可见设备数，
  `devices list` 把 Network 显示为 Wi-Fi。
- 无线原理：先用 USB 信任一次 → `flc wifi on` 打开 iPhone 的 Wi-Fi 同步
  （`pymobiledevice3 lockdown wifi-connections on`）→ AMDS 通过 Bonjour 广播该设备 →
  `usbmux list` 中出现 ConnectionType=Network → 复用现有 userspace tunnel，无需管理员。
  依赖 Windows 的 "Bonjour Service"（`Get-BonjourState` 会报告）。
- `flc_set.py`：新增 `--udid|-U`、`--wifi|-w`（`pick_network_udid()` 用
  `pymobiledevice3.usbmux.list_devices()` 筛 `dev.is_network`），run() 增加 wifi 重连提示。
- 文档同步：`flc help` + README.md + README-CN.md（新增 B 节无线快速开始、wifi 命令表、
  无线常见问题）。

## 发版流程（可复用）

1. 改完代码 → `git add -A && git commit -S`（全局 commit.gpgsign=true，gpg 程序为
   `D:\Software\GnuPG\bin\gpg.exe`）→ `git tag -s v1.3 -m "..."`（签名 tag）。
2. 打包到 `release/`（已加入 .gitignore）：
   - master 源码包：`git archive --format=tar --prefix=fake-location-cli/ v1.3 | gzip -n -9 > release/fake-location-cli-master.tar.gz`
   - portable 包：git archive 解压到 `release/build/fake-location-cli`，再拷入
     `assets/python|drivers|ddi`，`tar -czf`（约 105 MB，耗时约 3 分钟）。
3. GPG：`gpg --armor --detach-sign`（.asc）+ `sha256sum` → `SHA256SUMS.txt` +
   `--clearsign` 的 `SHA256SUMS.txt.asc`。密钥 BC265EF2902C197C4863EA49D361EDF9A59ECED9。
4. 推送：`git push origin master`（Gitee）与 `git push github master`，再 push tag。
5. Release 页面需 API 令牌（本机无 gh CLI、无 token）：GitHub PAT(repo) 与 Gitee 私人令牌。

注意：bash 里不能直接调 powershell（被安全策略拦截），改用 PowerShell 工具执行 PS 命令。
